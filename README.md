# ProFlow SaaS Platform 🚀

**ProFlow** היא מערכת SaaS מתקדמת לניהול עסק והפקת הצעות מחיר חכמות, המותאמת לשוק המקומי והבינלאומי עם ניהול מע"מ דינמי, אינטגרציית וואטסאפ, דיוור חכם ועוד.

🌐 **דומיין ייצור:** [https://www.quotecodepro.com/](https://www.quotecodepro.com/)

---

## 🛠️ סטאק טכנולוגי (Tech Stack)
* **Frontend:** React (Vite)
* **Backend & Database:** Supabase (Auth, Database, Edge Functions)
* **Hosting & CI/CD:** Vercel
* **Version Control:** GitHub

---

## ✨ פיצ'רים מרכזיים במערכת
* **ניהול הצעות מחיר חכם:** יצירה, עריכה, שכפול וייצוא נתונים (CSV).
* **מנגנון חוקיות מע"מ אוטומטי:** חישוב 18% ללקוחות מקומיים ו-0% ללקוחות בינלאומיים.
* **דיוור ענן מאובטח:** שליחת הצעות מחיר באמצעות Supabase Edge Functions ו-Resend תחת דומיין מאומת (`info@quotecodepro.com`), כולל נוריות חיווי סטטוס בזמן אמת.
* **אינטגרציית WhatsApp:** קישורים דינמיים לשליחת הצעות ישירות ללקוחות עם נורמליזציה של מספרי טלפון.
* **פאנל ניהול Super Admin:** שליטה על מנויים, שינוי חבילות, הענקת מנויי Lifetime, ומעקב משתמשים בזמן אמת.
* **מרכז שליטה פיננסי:** דוחות הכנסות מול הוצאות וגרפים חזותיים מתקדמים (Recharts).
